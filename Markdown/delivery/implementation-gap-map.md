## Laravel foundation slice (2026-10-19)

G01 and G02 are **Partial** on the running Laravel application. Control-plane firm, domain, verification, membership, credential, and provisioning tables exist, tenant routes now carry workspace modules, and host-verified public consultation routes establish tenant context before writes. Evidence: [firm tenant schema foundation](../architecture/firm-tenant-schema-foundation.md) and `laravel-backend/tests/Feature/FirmTenancyTest.php`. Remaining gaps are production enforcement of strict per-firm DB users (no shared fallback), legacy shared-row retirement, and broader SaaS cell/subscription capabilities. The "Current" cells below this note still describe the 2026-10-12 ASP.NET tree unless a later sentence says otherwise.

On 2026-10-22, firm onboarding moved from admin-only registration to a mixed applicant + platform-review flow: applicant registration endpoints, revision-bound verification records, and two-person approval records are now in the Laravel control plane (`firm_onboarding_*` tables, `FirmOnboardingService`, and `FirmOnboardingApiTest`). Production-grade external business-verification providers are still **not implemented**; provider mode fails closed when unconfigured.
